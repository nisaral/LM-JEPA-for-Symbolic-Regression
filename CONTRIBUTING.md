# Contributing

Thanks for taking a look. Small, focused contributions are very welcome: bug fixes, tests, docs, and
anything labelled [good first issue](https://github.com/nisaral/LM-JEPA-for-Symbolic-Regression/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
or [help wanted](https://github.com/nisaral/LM-JEPA-for-Symbolic-Regression/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22).

## Getting set up
Open `LM_JEPA_Symbolic_Regression_GSoC2026.ipynb` in Jupyter or Colab and run all cells (it installs its own dependencies). A GPU is optional.

## Making a change
1. Fork the repo and create a branch.
2. Keep the change small and explain *why* in the PR description.
3. Before opening the PR: re-run the notebook top to bottom and commit it with outputs, and report any metric changes with the seed you used.
4. Never commit API keys, `.env` files, or large data/model files.

## Reporting bugs and ideas
Open an issue using the templates. For bugs, include the exact command, the full error and your environment.
If you are unsure whether something is in scope, open an issue first and ask.
